## 📌 About The Project

This project is a browser-based calculator that performs basic mathematical operations.

It was created to practice DOM manipulation, event handling, and JavaScript calculation logic.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear display button
- ⚠️ Division by zero validation
- ⚡ Dynamic display updates

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
